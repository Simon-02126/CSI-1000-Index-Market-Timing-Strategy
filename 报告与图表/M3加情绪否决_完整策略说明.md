## 0. 一页摘要

一句话逻辑：**用「量价深度学习因子」+「两融/市场规模因子」两套独立信号合成三档仓位，再用「股指期货会员持仓多空比」作为独立否决层，在最悲观的持仓结构区间强制清仓。**

| 指标 | 策略（M3+情绪否决） | M3 基准（无否决层） | 买入持有 |
|---|---|---|---|
| 累计收益 | **172.5%** | 125.9% | 41.4% |
| 年化收益 | **14.2%** | 11.5% | 4.9% |
| 年化波动 | **13.8%** | 15.2% | 24.7% |
| 夏普比率 | **1.03** | 0.76 | 0.20 |
| 最大回撤 | **-25.8%** | -30.5% | -46.7% |
| Calmar | **0.55** | 0.38 | 0.11 |

关键结论：
- 相对指数年化超额 **+9.29%**，超额 IR 0.54，超额 t = 1.45。

## 1. 策略逻辑全链条

```
原始数据                  因子视图                信号                    仓位
─────────────────────────────────────────────────────────────────────────────
行情 OHLCV/成交额  ──►  pv 视图（150×8）  ──►  LSTM+注意力  ──┐
                     （量价序列）              6 seed 均值      │
                                                              ├─► 滚动300日分位
两融余额/市场规模  ──►  slow 视图（10维）  ──►  MLP      ──┐  │   → slow 拉伸
                     （资金面静态截面）        6 seed 均值  │  │   → 等权 0.5/0.5
                                                            └──┴─► 三档 0.30/0.80
                                                                   → 5日众数平滑
                                                                        │
IF 会员持仓多空比  ──►  250日分位 < 0.20 且连续3日 ─────────────────────► 否决：仓位清零
```

### 1.1 数据层

| 视图 | 原始字段 | 预处理 |
|---|---|---|
| **pv（量价）** | 日线 8 通道：收益率、日内位置、振幅、量比、换手率、成交额占比等 | 标准化；取最近 **150 个交易日** 为一条样本 |
| **slow（资金面）** | 两融余额、融资买入额、市场规模 5 个字段 × 2 种变换 = 10 维 | 横截面标准化，当日静态截面 |
| **情绪面板** | 期权 PCR（成交量/持仓量）、50ETF/300ETF/500ETF 隐含波动率、偏斜、期货会员多空比（IF/IC/IM/IH） | 落盘于 `input\情绪_面板_日频.csv`，2015-02-09 起 2840 个交易日 |

### 1.2 因子层：两个独立视图

- **pv 视图**：150 日 × 8 通道 → LSTM(8→64) → 注意力池化 → MLP(64→128→64) → 64 通道取均值 = 1 个量价信号。
- **slow 视图**：10 维静态特征 → MLP(10→128→64) → 均值 = 1 个资金面信号。
- **标签**：`ln(close_{t+10} / close_t)`，按训练集内 z-score 标准化。
- **训练方式**：滚动年度切分 —— 训练 `< Y-3`、验证 `[Y-3, Y-1)`、测试 `Y`；embargo = `max(HORIZONS)+1` 天防泄漏。
- **稳定性处理**：每个视图训练 **6 个随机种子**，取信号均值（seed 0-5）。
- 关键常量（`timing_model.py`）：`N=150`、`HORIZON=10`、`HID=64`、`LAMBDA_CORR=0.1`、`FIRST_TEST_YEAR=2015`。

### 1.3 信号合成（M3）

```
1) 两个信号各自做 300 日滚动分位（严格保序：o[i] = count(v[lo:i] < v[i]) / (i-lo)）
2) slow 分量拉伸：slow_s = clip((slow_pct - 0.30) / 0.35, 0, 1)        ← 0.65 封顶，修 slow 的 Q5 死区
3) 合成：comp = 0.5 * pv_pct + 0.5 * slow_s
4) 三档：pos = 0.0 if comp < 0.30；0.5 if comp < 0.80；1.0 otherwise
5) 平滑：最近 5 日取众数（mode-5），抑制抖动
```

> 为什么 slow 要拉伸：slow 的 5 箱测试显示 Q4 最好（+1.92%）、Q5 反而为负（-0.54%），说明原始分位在 0.65 以上不含额外信息，直接按 0.80 分档会落进死区。拉伸到 0.65 封顶后夏普 0.72→0.76，2022 年 -12.7%→-7.1%。

### 1.4 情绪否决层（方案 D 最优版）

**触发条件**（唯一一条，不加任何确认条件）：

```
IF_会员多空比 的 250 日滚动分位 < 0.20，且连续 3 个交易日满足
→ 当日仓位强制 = 0（清仓，不是砍半）
→ 条件解除即恢复原 M3 仓位
```

实现：

```python
cond = (IFp < 0.20).rolling(3, min_periods=3).sum().fillna(0) >= 3
pos  = base.where(~cond.reindex(base.index).fillna(False), 0.0)
```

#### 字段溯源（整个否决层只用了 1 个字段）

```
中金所 会员持仓排名（akshare: ak.get_cffex_rank_table(date, vars_list=["IF","IC","IM","IH"])）
  └─ 逐合约取前 20 名会员行 → 求和 long_open_interest / short_open_interest → 跨所有月份合约加总
       ↓
input\情绪_期货会员持仓.csv   列：日期 | 品种 | 前20_持买单量 | 前20_持卖单量 | 会员多空比 | 合约条数
       ↓  （按 日期 透视为宽表，与 中证1000 交易日对齐）
input\情绪_面板_日频.csv      列：IF_会员多空比 / IC_会员多空比 / IM_会员多空比 / IH_会员多空比
       ↓
否决层只读 IF_会员多空比 这一列，其余 28 列（PCR、IV、偏斜、IC/IM/IH）全部测过并弃用
```

- **定义**：`会员多空比 = 前20会员持买单量 / 前20会员持卖单量`（IF，沪深300 股指期货）。
- **原始值特征**（2015-02-09 ~ 2026-10-21，2840 日）：均值 0.88，最小 0.75，最大 1.08，5% 分位 0.78、95% 分位 1.01。常态 < 1，因为套保空头占优。
- **它衡量的是「机构对冲盘有多拥挤」**：前 20 会员的卖单（空头）相对买单（多头）越多，说明机构在期货上压的空头越重，对应现货端的防御姿态。
- **为什么用滚动分位而不是原始值**：原始值有长期水平漂移（2021 年触发时约 0.82、2024 年约 0.75、2026 年约 0.83），固定阈值会失效；250 日滚动分位自动适应水平漂移。

**触发频率**：全样本 250 日分位 < 0.20 的日数占 24.8%，加「连续 3 日」确认后剩 565 个触发日 / 48 段；落在回测区间（2019-06 起）内的是 **30 段 / 320 天**。

**为什么是 IF 会员多空比**：对全部候选情绪指标做了「滚动分位 → 未来 10 日收益」的分箱检验（全样本 2015-2026，2770 日）。

`IF_会员多空比` 分位分箱（单调）：

| 分位区间 | n | 未来10日收益 | 胜率 |
|---|---|---|---|
| 0.00-0.10 | 475 | **-1.58%** | 36.2% |
| 0.10-0.20 | 230 | **-1.40%** | 39.6% |
| 0.20-0.40 | 439 | -0.42% | 49.7% |
| 0.40-0.60 | 404 | -0.31% | 51.2% |
| 0.60-0.80 | 468 | -0.30% | 51.3% |
| 0.80-0.90 | 254 | +0.61% | 58.7% |
| 0.90-1.00 | 500 | **+1.65%** | 66.8% |

Spearman IC = **+0.197**（全样本，含 2015-2026，不限于回测区间）。

其他候选全部弃用：

| 候选 | 低分位(0-10%)后10日 | 高分位(90-100%)后10日 | Spearman IC | 结论 |
|---|---|---|---|---|
| **IF_会员多空比** | **-1.16%**（n=42） | **+1.13%**（n=40） | **+0.172** | ✅ 单调，可用（t(低-高) = -1.99） |
| IC_会员多空比 | — | — | +0.010 | ❌ |
| IM_会员多空比 | — | — | -0.066 | ❌ 方向相反（且仅 2022-07 起有数据） |
| IH_会员多空比 | — | — | ≈0 | ❌ |
| 50ETF_IV 平值 | **+1.37%** | — | +0.028 | ❌ 分位>0.9 后是**正**收益（恐慌即买点） |
| 50ETF_PCR成交 | **+2.09%** | — | +0.046 | ❌ 同上，反向 |
| 50ETF_PCR持仓 | — | — | +0.053 | ❌ 偏弱 |
| 50ETF_IV沽购比 / 偏斜 | — | — | +0.108 / +0.144 | ❌ 与未来10日相关为正（反指），不能用于做空 |

**这次检验推翻了最初的设计**：原本打算用 IV 分位 > 0.90 做否决，但前瞻一测方向是反的——用 IV 做否决等于在市场最恐慌时减仓，错过了反弹。之前觉得「IV 极值对应大跌」是**同期相关**的错觉。

#### 为什么不用 IC 更高的那些字段（重要，避免误读）

全样本重算后，有一批情绪字段的**全样本 IC 比 IF 更高**（例如 `500ETF_IV平值` IC = +0.200 / t = 6.22 vs IF 的 +0.109）。选 IF 不是因为它的 IC 最高，而是因为**只有它在四项筛选上同时不塌**：

| 筛选维度 | IF_会员多空比 | 高 IC 但被淘汰的字段 |
|---|---|---|
| **符号稳定**（分 4 段各自算 IC） | +0.071 / +0.183 / +0.189 / +0.122，**4/4 同号，极差 0.12** | `50ETF_IV平值` +0.193 / **-0.165** / +0.258 / +0.100（翻转）；`300ETF_IV平值` -0.201 → +0.245（翻转） |
| **样本覆盖** | 2015-02 起 **2830 日**，覆盖全部回测区间 | `500ETF_*` 2022-09 起仅 950~980 日；`300ETF_*` 2019-12 起 1640 日 |
| **不是波动率代理** | IC(fwd) = +0.109 > IC(\|fwd\|) = +0.033（方向性强、波动性弱） | IV 族普遍反过来：`50ETF_IV平值` IC(fwd) +0.117 < IC(\|fwd\|) **+0.249**；`500ETF_IV平值` +0.200 < **+0.230** → 预测的是波动幅度不是方向 |
| **与已有信号正交** | 对 pv 回归取残差后 IC 仍有 **+0.177**（几乎不衰减） | `50ETF_IV沽购比` / `IV偏斜` / `300ETF_IV偏斜` 与 IF 相关 **0.41 / 0.41 / 0.53**，正交 IF 后 IC 从 0.13~0.14 掉到 **0.04~0.07** → 是 IF + slow 的混合物 |

其他被否的具体原因：

- **`IH_会员多空比`**（IC +0.076，4/4 同号，极差 0.11，稳定性与 IF 相当）—— 但它与 IF 的相关系数 **0.861**，是同一个东西的两种写法，加进来等于加重权重。
- **`IC_会员多空比`**（2019-2021 段 IC 曾达 +0.308）—— 全样本只有 +0.019，2024-2026 转负 -0.029，不稳定。
- **`IM_会员多空比`**（IC = -0.112）—— 它与 `IC_会员多空比` 相关 **+0.785**，是 IC 的镜像；与 IF 相关 **-0.455**。所谓「IM 方向相反」是**品种差异**造成的，不是数据缺陷，也因此不提供新信息。
- **`50ETF_PCR成交`**（IC +0.044）—— 与**过去** 10 日收益相关 **-0.160**，与未来只有 +0.044：典型**反指/同期变量**，没有预测力。IC 分段 -0.018 / +0.186 / +0.179 / -0.012 符号还翻。
- **`50ETF_PCR持仓`**（IC +0.039）—— 与过去 10 日收益相关 **+0.320**（同向滞后），同样是描述已发生的事。
- **`500ETF_PCR成交`**（IC -0.084，单调性 -0.87）—— 单调但方向为负，且 2022-09 起仅 978 日、分段符号翻转（+0.123 → -0.151）。

补充两个量化事实：
- **28 个字段并不等于 28 次独立检验**：标准化后 PCA 的**有效独立方向数只有 ≈9.6**（前 3 个主成分解释 47.3%）；跨标的相关：`corr(50ETF_IV平值, 300ETF_IV平值) = 0.943`、`corr(IF, IH) = 0.861`、`corr(IC, IM) = 0.785`。
- **多重检验门槛**：样本量中位数 1638，检验 22 个候选时 Bonferroni 临界 |IC| = **0.075**（t≈3.05）。按这个门槛「通过」的字段有一批，但它们在正交 IF 后基本都掉到 0.10 以下 —— 真正独立的信息量远小于表面 IC 的排名。

**唯一还值得再试的候选**：`500ETF_IV平值`。它是全表最强（IC +0.200 / t 6.22，两段 +0.316 / +0.169），且注意它的方向与我们原本的设想**相反**——高 IV 对应**正**收益，即它是「恐慌买点」而不是「恐慌否决」。但在用它之前必须接受三个硬约束：① 只有 2022-09 之后 965 个样本，无法覆盖 2019-2021，也无法做真正的样本外；② 与 IF 相关 **0.497**，正交 IF 后 IC 从 +0.200 掉到 **+0.101**，一半是重复信息；③ IC(|fwd|) = +0.230 > IC(fwd)，主要是波动率代理。所以它最多能当**第四条腿（加仓线）**，不能替代否决层。

**关于 IF 自己正在衰减（必须知道的风险）**：把「分位<0.20 后未来 10 日收益」分年代看 —— 2015-18 无数据段、2019-2021 **-1.94%**、2022-2023 **-1.28%**、2024-2026 **-0.37%**，**单调衰减**。这与「overlay 的增益集中在 2021-2023、2024 后几乎不贡献」完全一致，是同一个事实的两种观测。这条腿的边际效用在减弱，实盘前需要重新评估其权重。

## 7. 归因

### 7.1 全年份恒等式（log %）

```
躲跌收益 637.3  −  踏空损失 569.8  −  成本 1.8  =  超额 65.6
```

恒等式与实际 `strat.sum() - bh.sum()` 完全吻合（+65.6 vs +65.6）。含义：
- 择时的毛收益来自躲跌（637.3），但被踏空（569.8）吃掉 89%。
- **净效率只有 10.3%**（65.7 / 637.3）—— 这是择时策略的常态，也解释了为什么这类策略必须把成本压到 0.3%/年以下（成本只要涨到 2%，超额就没了）。

### 7.2 否决层事件级归因

30 段触发、累计 320 个交易日清仓（占样本 18.0%）。

| 项目 | 数值 |
|---|---|
| 有净正贡献（有效） | 16 段，合计 **+25.7 pct** |
| 负贡献（无效） | 14 段，合计 **-6.5 pct** |
| 净贡献 | **+19.2 pct**（= 策略与 M3 全部逐日差异之和，已核对零残差） |
| 有实际影响的触发（当时基础仓位 > 1%） | 23 段 → 命中 16 / 恶化 7 = **命中率 70%** |
| 无实际影响（当时已空仓，触发无成本） | 7 段 |

**胜负最大的 5 段**：

| 开始 | 结束 | 空仓日 | 区间指数 | 基础仓位 | 净贡献 | 判定 |
|---|---|---|---|---|---|---|
| 2023-06-15 | 2023-11-02 | 93 | -9.7% | 79% | **+7.70 pct** | 有效 |
| 2021-12-16 | 2022-02-10 | 35 | -12.1% | 29% | **+3.38 pct** | 有效 |
| 2021-02-23 | 2021-03-08 | 10 | -5.6% | 27% | +2.70 pct | 有效 |
| 2020-10-13 | 2020-10-23 | 9 | -5.7% | 40% | +2.46 pct | 有效 |
| 2020-07-08 | 2020-09-29 | 60 | -5.1% | 61% | **-2.36 pct** | 无效 |

- 最大单笔收益 +7.70 pct 来自 2023 年下半年的阴跌，基础仓位已高达 79%，否决层把它清零，正好躲掉 -9.7%。
- 最大单笔亏损 -2.36 pct 来自 2020 年 7 月：这一段**区间是跌的（-5.1%）但先有两周急涨**（07-09 +2.9%、07-13 +3.5%），否决层在急涨初期清仓，把涨的部分吐了出去。这是「慢变量否决」的固有代价 —— 它抓不住 V 型反转。
- 2022-12-19 ~ 2023-01-04（-1.49 pct）同样是踏空型失败：基础仓位 77%，指数 +1.5%。

### 8.2 安慰剂检验（300 次循环平移）

把否决序列在时间轴上循环平移，破坏与时点的对应关系但保持触发频率、长度、仓位降幅不变。

IS = 2019-06~2022-12，OOS = 2023-01~2026-09，15 组参数网格：

### 8.4 正交性（5 项独立证据）

1. **信号层**：`corr(IF, slow) = -0.011`、`corr(IF, pv) = +0.033`；领先滞后 k = -60~+60 全部 |ρ| < 0.08。
2. **触发日基础仓位反而更乐观**：320 个触发日中，空仓 19.4% / 半仓 47.8% / **满仓 32.8%**，平均 57% > 非触发日 47%。
3. **可加性**：pv-only 0.375→0.654（Δ+0.279）、slow-only 0.321→0.614（Δ+0.293）、M3 0.758→1.026（Δ+0.268）—— 三个 Δ 几乎相同。
4. **恒定折扣对照（最干净的证据）**：把 M3 仓位统一乘 `k = 0.39/0.491 = 0.7943`，让它与否决层的平均仓位完全相同 → 夏普 **0.758（分毫未变）**、年化 9.2%；否决层同样 39% 均仓 → 夏普 1.026、年化 14.2%。**Δ年化 +5.0 pct 全部来自时点选择。**
5. **108 组（3 基底 × 36 seed）全部正增量**：pv-only Δ+0.277 / slow-only Δ+0.279 / M3 Δ+0.217，无一组为负。

> 但否决层**不能替代 slow**：pv+否决 0.654、slow+否决 0.614，都低于 M3 本身 0.758。它是第三条腿，不是替代品。

## 9. 局限与风险（不可省略）

1. **2024 年初小微盘流动性危机没有覆盖**。那段 -26.7% 里否决只命中 8%，日均仓位仍有 68%。IF 会员持仓是**慢变量**，抓阴跌不抓杠杆踩踏式闪崩。2025 关税冲击同样只覆盖 2%。
2. **增益高度集中在 2021-2023（+15.5 pct）**，2024 以后几乎不贡献。正交性检验证明这不是信号冗余，而是 IF 只在「阴跌型」结构里有效 —— 换句话说，这个否决层是**特定市场结构的产物**，结构变了它就失效。
3. **尾部覆盖明细**：2021 末-2022 调整（-34.0%）覆盖 30% ✓；2022 二次探底（-10.6%）覆盖 0%；2020 疫情（-9.0%）覆盖 8%；2024 阴跌覆盖 0%（基础信号已躲开，日均仓位仅 14%）。
4. **日均仓位从 49% 降到 39%**，若要保持与 M3 相同的风险预算，需要约 1.25 倍杠杆。上表所有夏普已是「单位仓位」口径，可以直接比较。
5. **250 日窗口是尖峰**（见 §8.5），存在参数拟合嫌疑。
6. **单品种单参数**：只用 IF 会员多空比一条线，IM（中证1000 自己的期货）反而方向相反且历史只有 2022-07 起。没有交叉验证。
7. **未做 PBO / CSCV** —— 这是项目至今唯一空白的过拟合定量检验，也是进实盘前的最后一道门槛。
8. **2026 年数据只到 9 月底**，2026 的 12.3% 不是全年。
9. **情绪数据 2026-10-21 之后需重新抓取**（akshare 侧会员持仓为日更）。
10. 2021 年 -14.6% 的超额是结构性的（三档 + 空仓设计在慢牛里必输），不通过改因子能修，只能改结构（加杠杆/加动量腿）。

## 10. 口径说明

- **收益**：对数收益 `ln(P_t/P_{t-1})`；累计收益为 `exp(sum)-1`。
- **仓位生效**：T 日收盘出信号、T+1 日收益按新仓位计提（`pos.shift(1)`）。
- **成本**：单边 3bp × `|Δpos|`，当日计提，计入策略收益。
- **年化**：`mean * 252`；波动 `std * sqrt(252)`；夏普 = 年化收益 / 年化波动（无风险利率取 0）。
- **最大回撤**：基于累计对数收益曲线。
- **上行/下行捕获**：月度口径，`策略该组均值 / 指数该组均值`（复利还原后）。
- **分年**：2019 从策略起点 06-04 起算，2026 止于 09-30，其余为完整自然年（收益按连续收盘价计算，无跨年断点）。
- **超额**：策略与指数对数收益逐日相减。
- **归因恒等式**：`躲跌 = Σ(1-w)·max(-r,0)`、`踏空 = Σ(1-w)·max(r,0)`、`成本 = Σ|Δpos|·3bp`。
- **否决层事件**：以触发段为单位，区间指数收益取「实际空仓生效的收益日」区间（T+1 至恢复仓位前一日）；净贡献为该区间内 overlay 与 M3 的逐日收益差之和（含额外成本），30 段之和与全样本逐日差总和零残差。
