# 中证1000 择时研究记录（截至 2026-10-25）

> 本文件汇总本次会话的全部关键实验结论，供后续决策与复现使用。
> 数据口径：中证1000、64 通道、pv/slow 视图；评估 2019-01 ~ 2026-10；成本单边 3bp；三档仓位（0/0.5/1）+ 离散众数平滑 + 滚动分位窗口。

## 一、数据基础（不可改动的前提）

| 项目 | 事实 |
|---|---|
| 中证1000 行情（本地） | `data/` 有 2005-01-04 起，但 `input/` 只从 **2012-01-04** 起（人为截断） |
| 换手率有效性 | 中证1000 **2014-10-17 之前全为 0**（指数发布日，未回填） |

| 已知缺陷 | 2017 年 pv 信号标准差 7.6e-17（换手率通道 std≈0 导致输入爆炸，信号恒定） |

## 二、因子评估（量价因子 pv）

### 2.1 IC / ICIR（single 10日标签，2019+）

| 指标 | H=10 | H=20 |
|---|---|---|
| 重叠 IC | 0.090 | 0.111 |
| 非重叠 IC | 0.090 | 0.172 |
| 非重叠 RankIC | 0.122 | 0.198 |
| 年度 IC 均值 | 0.240 | — |
| 年度 ICIR / t | 1.15 / 3.26 | — |
| **月频 ICIR / t** | **0.17 / 1.64（不显著）** | — |

- IC 随持有期单调上升（1 日 0.037 → 20 日 0.172）→ **中长周期趋势型因子**
- 64 个通道之间相关性 **0.966**，`corr_penalty` 实际未生效，等权平均 ≈ 任意单通道
- 分层形状：Q4 最优(+2.01%)、Q5 回落(+0.90%)、Q2 最差(-1.55%) → 单调性秩相关仅 0.6；但 **3~4 箱下完全单调**（不单调主要是分层过细的噪声）
- 高波动期 IC 0.066 vs 低波动 0.139 → **波动率翻倍时预测力减半**
- 与 slow 相关 0.145（正交性良好）；正交化后增量 IC 0.078

### 2.2 版本对比（各自最优 W,k）

| 版本 | 最优 (W,k) | seed | 单因子夏普 | 组合夏普 | 组合 19-24 | 组合 2026 | OOS pooled IC | seed std |
|---|---|---|---|---|---|---|---|---|
| **双期 5+10 MSE** | W=200,k=15 | 5 | **0.77** | 0.51 | 0.42 | -0.01 | **+0.024** | **0.10** |
| **三期 5+10+20 IC** | W=750,k=5 | 1 | 0.67 | **0.69** | **0.59** | **+0.56** | -0.094 | — |
| 单 10 日（现行） | W=200,k=7 | 6 | 0.76 | 0.56 | 0.42 | -0.49 | -0.083 | 0.15 |
| 双期 5+10 IC | W=300,k=15 | 1 | 0.47 | 0.25 | 0.25 | — | — | — |
| 20 日标签 | — | — | 已淘汰（逐年 IC 3/7 为负，均值 -0.017） | | | | | |

**结论**：双期MSE 综合最优（3 项第一），但**必须配短窗口 W≈200**；三期IC 组合层最强但 OOS IC 最差且仅 1 seed；单10日 在 2026 组合层最差（-0.49）。所有差距均小于种子噪声。

## 三、训练随机性（决定性发现）

单 10 日、64 通道、6 个独立 seed 训练：

| 指标 | 结果 |
|---|---|
| 跨 seed 信号相关（全期） | **均值 0.14，最差 -0.14**（单年出现过 -0.45） |
| 单 seed 组合夏普 | 0.46 / 0.48 / 0.26 / 0.47 / 0.61 / 0.75，均值 **0.50**，std **0.16**，min **0.26** |
| 6 seed 平均组合夏普 | 0.50（不加分，只降方差） |
| 因子层 t 值最差的 seed | **1.14（不显著）** → 约 1/6 概率训出"没信号"的模型 |
| 逐年收益跨度 | 2020 年 2.5%~19.0%、2022 年 -11.1%~+6.0%、2025 年 8.2%~32.0% |

**含义**：种子噪声与信号强度同量级 → **单次训练结果不可复现**，任何小于 0.15 夏普的版本差异都不成立。

## 四、准入检验（7 项门槛）

| 门槛 | 标准 | 结果 |
|---|---|---|
| S1 因子层 | IC t≥2 且 ICIR≥1 | 四个版本全过 |
| S2 尾部区分度 | 分箱多空 ≥1.5%/10日 | 单10日/双期MSE ✗（seed 平均后只剩 0.41/1.29）；三期IC ✓（2.19） |
| S3 阈值覆盖 | q90≥0.85 且满仓≥8% | 双期MSE ✗（W=750 时 q90=0.56、满仓 7%）；其余 ✓ |

| S5 真样本外 | 2025-26 池化 IC>0 | **只有双期MSE ✓（+0.024）** |
| S6 seed 下限 | 最差 seed 的组合夏普 ≥ slow 单因子(0.357) | **全部 ✗**（单10日 min 0.26 / 双期MSE min 0.31） |
| S7 正交性 | \|corr\|<0.3 | 全过（0.03~0.13） |

**没有任何版本通过全部 7 项**。S6 是最硬的关，也是"能否给固定权重"的决定条件。

### 5.2 三个代表性方案正面对比

| 方案 | 全期 | 2019-24 | 2025 | 2026 | 年化 | 回撤 | Calmar | 均仓 |
|---|---|---|---|---|---|---|---|---|

| 双期MSE 单点最优（w=0.5, W=500, k=15） | 0.60 | **0.53** | 2.39 | -0.09 | 8.5% | **-24.4%** | **0.35** | 39% |

## 六、已否定的方案（避免重复踩坑）

| 方案 | 结论 |
|---|---|
| 20 日标签 | 负优化（H=20 IC 均值 -0.017，逐年 3/7 为负） |
| 滚动 z-score 标准化（减均值除 std） | 破坏趋势，IC 归零（H=10 从 0.090 → -0.016）；**必须用滚动分位（保序变换）** |
| 扩张窗口 z-score（现行旧法） | 信号水平漂移时失效：z>0 仅占 1% 天，满仓占比 4% |
| 最短持有 N 日代替平滑 | 无效（h=3~20 夏普 0.34~0.49），只解决"多久能改"不解决"抓哪天锁哪天" |
| 合成后 re-rank | 整体变差（夏普 0.66→0.46；满仓 13%→30%，2026 从 +13.2% 掉到 +4.3%）；仅在单因子场景有效（slow 0.246→0.442） |
| 仓位层加权替代分位平均 | 变差（0.662 → 0.341） |
| 波动率目标 vol target | 变差（0.58 → 0.35），A 股波动放大常伴趋势 |
| 估值维度（ERP） | 华泰实证：对中证 500/1000/2000 为**负**贡献，中证1000 不应加 |
| 条件期望映射（让数据学分层收益） | 彻底失败（夏普 -0.21/-0.34），188 个独立观测撑不起分箱估计 |
| 情绪面作为等权第三因子 | 功效计算：新因子 IC 需 ≥0.20 才不拖累；安慰剂式测试显示 IC 0.10 时三维组合 0.46 < 双因子 0.635 |

## 七、当前建议

### 因子选择
1. **量价因子**：保持**单 10 日、64 通道**不动。它是唯一有 6-seed 完整分布、且单 seed 层面最稳的版本（0.26~0.75）。
2. **双期 5+10 MSE**：作为候选跟踪，若要用必须 ①W≈200~500 短窗口 ②w_pv 压到 0.25 ③先训到 10 seed 验证。
3. **不要**在量价因子族上继续做版本迭代——所有差异都小于种子噪声。

### 仓位规则
- 信号日频生成（必须）；目标档位日频计算；实际下单由"众数 5~10 日"自然控制到 7~12 次/年
- 三档阈值 0.30/0.80，离散众数平滑（众数5 在全期最好，众数10 平台更稳）
- 分位窗口 W：单10日 用 200~750 均可（严格选 200），双期MSE 必须 ≤500

### 待办
1. **slow 因子过同一套 7 项门槛**（它是组合主力：slow 单因子 0.357，re-rank 后 0.442）← 最高优先级
2. 候选版本（双期MSE）补到 10 seed
3. PBO / CSCV 过拟合检验
4. 情绪面做成**极值触发的减仓开关**（非等权因子），完全不引入训练随机性
5. 修复数据缺陷：中证1000 换手率（2014-10-17 前为 0）、2011 年列错位

### 8.5 正交性与状态特征（slow 的真正价值）

- 与 pv 相关 **-0.016**（几乎完全正交），正交化后 IC 从 0.073 → 0.074（**增量全部保留**）
- 状态分层 IC：**熊市 0.144（RankIC 0.241）vs 牛市 0.038（RankIC 0.041）**、高波动 0.112 vs 低波动 0.079
- → **slow 是"下跌保护"因子，不是"上涨增强"因子**（与 pv 恰好互补：pv 高波动期失效，slow 高波动期更有效）

### 8.6 准入判定

| 门槛 | slow 结果 | 判定 |
|---|---|---|
| S1 因子层 | IC 0.170 / t 2.98 | ✓（但 2/6 seed 不显著） |
| S2 尾部区分度 | 多空 -0.28%（Q5 为负） | ❌ |
| S3 阈值覆盖 | q90 0.85 / 满仓 15% | ✓ |
| S4 参数平台 | W=150 均值 0.46；W=750 仅 0.19 | ⚠️ 对窗口敏感 |
| S5 样本外 | 池化 IC -0.102 / -0.037 | ❌ |
| S6 种子稳定 | W=300 时 std 0.03；因子层 2/6 不显著 | ⚠️ 组合稳、因子不稳 |
| S7 正交性 | -0.016 | ✓✓ 最佳 |

**通过 3.5/7**。结论：slow 也不通过严格准入，但它的**正交性与种子稳定性显著优于 pv**，且经济逻辑清晰（熊市有效）。

**可执行结论**：
1. slow 不要用 0.8 满仓阈值（Q5 是死区），改用 hi=0.6~0.7 或线性 `clip((pct-0.2)/0.4)`
2. slow 的定位是"下跌保护/减仓开关"，pv 的定位是"趋势跟随"
3. 但因 2026 结果在 seed 间两极分化，这些阈值优化仍无法确定可信最优 → 需先扩到 10 seed

## 九、最终方案 M3 的因子逻辑

### 9.1 整体逻辑（一句话）

> **用量价因子判断"趋势是否在场"（右侧），用杠杆资金因子的拥挤度判断"风险是否已累积"（左侧）；两者近乎正交，等权叠加后映射成 0/50/100% 三档仓位，并在杠杆拥挤度进入中高位（0.65）时即视为充分定价。**

### 9.2 因子 A：量价（pv）

| 项目 | 内容 |
|---|---|
| 输入 | 150 天 × 8 通道：开/高/低/收相对窗口末收盘价的对数比、VWAP 相对值、成交量/成交额/换手率的窗口均值标准化 |
| 结构 | LSTM(8→64) → 注意力池化 → MLP(64→128→64) → 64 通道取均值 |
| 训练 | 标签 = 未来 10 日对数收益的 z 值；滚动切分（train<Y-3, valid=[Y-3,Y-1), test=Y） |
| 经济含义 | **量价配合的趋势延续性**：价格形态 + 成交量确认 → 趋势自我强化 |
| 实证特征 | IC 随持有期上升（1 日 0.037 → 20 日 0.172）→ 中长周期趋势型；分箱 Q4 最优(+2.20%)、Q5 回落(+0.86%)（动量过热）；**高波动期失效**（IC 0.139→0.066） |
| 角色 | **右侧跟随**：趋势确认后跟上（2025 年 +27.4%），趋势翻转时滞后 |

### 9.3 因子 B：两融/市场规模（slow）

| 项目 | 内容 |
|---|---|
| 输入 | 5 个市场级字段 × 2 变体 = 10 维静态特征：全市场融资余额、融券余额、融资净买入额 + 板块总市值、板块上市股票数；存量取 log(水平/滚动均值) 与 log(水平/超前 n 日)，流量取累计/存量与带符号强度；全部滞后 1 日（t+1 披露） |
| 结构 | 无时序模型，MLP(10→128→64) → 64 通道取均值 |
| 经济含义 | **杠杆资金的进出 = 风险偏好的边际变化**；融资余额高企 = 杠杆仓位拥挤 = 后续去杠杆压力 |
| 实证特征 | 分箱 **Q4 最优(+1.92%)、Q5 为负(-0.54%)** → 典型的"拥挤度"而非"方向"指标；**熊市 IC 0.144（RankIC 0.241）vs 牛市 0.038（RankIC 0.041）** → 主要在下跌时提供信息 |
| 角色 | **左侧防御**：判断下跌空间（2022 年组合仅 -7.1%，M0 是 -12.7%） |

### 9.4 为什么两者能互补

| 维度 | pv | slow |
|---|---|---|
| 信息类型 | 价格自我延续（趋势） | 杠杆仓位压力（拥挤度） |
| 时序位置 | 右侧（事后确认） | 左侧（事前预判） |
| 有效状态 | 趋势市、低波动 | 熊市、高波动 |
| 失效状态 | 高波动（IC 减半）、动量过热（Q5 回落） | 牛市（IC 0.038）、杠杆极值（Q5 为负） |
| 实测相关性 | **-0.016**（近乎完全独立，正交化后增量 IC 完整保留） | |

⚠️ 两条腿都有"Q5 回落"的共同缺陷——**极端高分位都不代表更强信号**，这是把阈值设在 Q4 区间（而非极端）的根本原因。

### 9.5 为什么 slow 要"0.65 饱和"（核心设计）

这是最终方案唯一偏离标准做法的地方，逻辑链：

1. slow 的信息集中在第 4 分位（前瞻 10 日 +1.92%），而最高分位 Q5 反而是 **-0.54%**
2. **经济解释**：两融余额/融资净买入额进入历史极高分位，意味着杠杆已经加满——后续是**去杠杆**而非继续上涨。它度量的是"拥挤度"，不是"看多程度"
3. 所以在"中高位"（分位 0.6~0.7）才对应"杠杆资金稳步流入、尚未拥挤"的健康状态；超过这个位置，信息价值不再增加甚至反向
4. 实现：`slow_pct_adj = clip((slow_pct - 0.30) / (0.65 - 0.30), 0, 1)` —— 0.65 以上一律视为满分
5. 这与华泰对期权 PCR / 隐含波动率用"反向布林带"、只在极值做反向是同一类处理：**情绪/杠杆类指标是拥挤度度量，天生不适合"越高越买"**

### 9.6 其它参数的存在理由

| 参数 | 取值 | 逻辑 |
|---|---|---|
| 滚动分位窗口 W | 300 日（约 14 个月） | 两融余额有长期增长趋势，绝对水平不可比；300 日匹配杠杆资金"季度~年度"的轮动节奏。太长（750 日）会跨过多个杠杆周期 |
| 标准化方式 | **滚动分位**（保序变换） | 不能用滚动 z-score：减均值会破坏趋势信息，实测把 IC 从 0.090 打到 -0.016 |
| 两条腿合成 | 分位等权平均 | 两腿相关 -0.016，等权即最优；**不能用仓位层加权**（实测 0.45~0.54 vs 0.55~0.76） |
| 仓位映射 | 三档 0.30 / 0.80（合成后） | 承认信号只有三档信心；离散化后实盘只有 3 种指令 |
| 平滑 | 众数 5 日 | 抑制阈值附近抖动（纯日频换仓 27~43 次/年，夏普仅 0.35） |
| 信号频率 | **日频生成** | 滚动分位窗口每天滚动；实际下单由众数平滑降到 6~12 次/年 |

### 9.7 这个体系的边界（不做什么）

- ❌ **不是收益增强 alpha**，是**仓位管理/风险预算工具**。单边慢牛会显著跑输（2021 年 +3.1% vs 买持 +18.7%）
- ❌ 不做个股/行业选择，只输出 0 / 50 / 100% 三档仓位
- ❌ 右侧因子的固有缺陷：趋势翻转初期滞后
- ⚠️ **收益高度依赖少数年份**：2025 +26.4%、2024 +22.3% 贡献主要收益；2022 靠 slow 少亏 7.1%
- ⚠️ **36 组 seed 配对均值仅 0.45~0.49**（单点 0.76），seed 不确定性仍是主导风险
