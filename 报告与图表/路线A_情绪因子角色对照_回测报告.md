# 路线 A 对照回测：情绪因子（IF 会员多空比）在策略里的三种角色

> 区间 2019-06-04 ~ 2026-09-30（1780 交易日 / 7.06 年）；单边成本 3bp 按 `|Δpos|` 当日计提；对数收益；夏普 = 年化 / 年化波动。
> 基准 base = M3（pv 6-seed 均值 + slow 6-seed 均值 → 300 日滚动分位 → slow 饱和 `clip((pct-0.30)/0.35,0,1)` → 0.5/0.5 等权 → 三档 0.30/0.80 → 5 日众数）。
> 情绪字段 = `IF_会员多空比` 的 250 日滚动分位（记作 IF）。

## 1. 三种角色

| 代号 | 角色 | 公式 |
|---|---|---|
| **B0** | 不用情绪（对照） | `pos = base` |
| **D（方向腿）** | 把 IF 当**第三个打分项**，与 pv / slow 一起进三档合成 | `comp = w1·pv + w2·slow + w3·IF` → 三档 → 众数（w3 做分位对齐保持档位占用率不变） |
| **V（否决腿）** | IF 只做**开关**：极端低位且连续 3 日 → 清零 | `pos = base where not trig else 0`，`trig = sustained(IF<0.20, 3)` |
| **A+（对称加减）** | IF 直接在**仓位层**做连续倾斜 | `pos = clip(base + IF − 0.5, 0, 1)` |
| **A\*（乘性）** | 仓位按情绪打折 | `pos = base × (0.5 + 0.5·IF)` |
| **Adn（只减）** | 只允许下调 | `pos = clip(base − clip(0.70 − IF, 0, 0.30), 0, 1)` |
| **Aup（只加）** | 只允许上调 | `pos = clip(base + max(0, IF − 0.70), 0, 1)` |

## 3. 传导通道诊断（为什么合成层失败）

| 事实 | 数值 |
|---|---|
| IF 分位 <0.20 后未来 10 日 | **-0.81%**（0-0.10 箱 -1.58%，0.10-0.20 箱 -1.40%） |
| IF 分位 0.20 ~ 0.90 各箱后未来 10 日 | 全部落在 **-0.42% ~ +0.61%（平坦）** |
| 否决触发日的基础仓位 | **56.7%**（非触发日 47.4%） |
| 同样这些天，D 方向腿把仓位压到 | **31.4%**（非触发日 53.9%） |
| 否决腿把仓位压到 | **0** |
| 否决降仓的 258 天里，D 方向腿也同时降仓的天数 | **162 天（62.8%）** |
| corr(IF 分位, 基础仓位) | +0.037（正交，不是重复信息） |

结论：**信息是真的，坏在传输通道。**
1. IF 的预测力几乎全部集中在极端下尾（20% 分位以下），0.20 以上是平的。
2. 在**合成层**，w3=1/3 时 IF 从 0 走到 0.20 只让合成值变动 1/3 × 0.20 = **0.067**，跨不过 0.30 / 0.80 的档位边界 → 事件被档位阈值吸收掉。
3. 在**仓位层**，同样的 0.20 位移就是 0.20 的仓位位移，不被任何阈值吸收。
4. 所以 D 方向腿识别到了同一批事件（62.8% 重叠），但只能把仓位压到 31%，而否决腿能压到 0。

## 5. 增量随样本龄的衰减（最决定性的一张表）

把全期切成三段，看各角色相对基准的**夏普增量**：

- **V 的增量稳定为正，从不翻负**（+0.28 → +0.25 → +0.04，只是变弱）。

- 机制：A+ 是**全时段下注**（每天、每个仓位都受 IF 影响），V 只在 18% 的交易日下注。而 IF 的符号稳定性在退化 —— 分位<0.20 后未来 10 日收益 2019-21 **-1.94%** → 2022-23 **-1.28%** → 2024-26 **-0.37%**，且 2025 年 IF 单年 IC = **-0.187（符号翻转）**。符号一翻，A+ 天天付代价，V 只在稀疏触发时受伤（2025 年 V 只触发 **1 天**）。

## 7. 结论与建议

1. **能不能把情绪因子合成进主信号？能，但不能在合成层。**
   把 IF 当第三个打分项（w3 从 0.10 试到 0.50，固定阈值与分位对齐两种口径），夏普 0.696~0.848，**全部低于基准 0.758**，同风险对照 Δ夏普为负。原因是 IF 的信息集中在极端下尾，线性权重在 0.30/0.80 档位阈值前被吸收（0.067 的位移跨不过档位边界）。

2. **在仓位层，两种用法都真实有效：**
   - **硬否决 V**：夏普 1.026（+0.268）、回撤 −25.8%、单位仓位年化 36.5%、安慰剂 p=0.000、36 组 seed 增量 100% 为正、三段增量 +0.28/+0.25/+0.04 **从不为负**。
   - **对称加减 A+**：夏普 **1.074**（全场最高）、Calmar **0.71**（全场最高）、36 组 seed Δ 均值 +0.275、最差 seed 0.448（全场最高）、安慰剂 p=0.000、10bp 成本下仍 0.994。

3. **两者取舍取决于对情绪信号未来的判断：**
   - 若认为情绪还会继续衰减/翻号 → 选 **V**。它靠稀疏性天然免疫，2025-26 仍 +0.04。
   - 若认为情绪至少维持现状 → 选 **A+**。点估计更高、Calmar 更好、最差 seed 更好。
   - **我倾向 V 作为生产版本**：A+ 的增量已经翻负（−0.23），而 V 从未翻负；A+ 的全部超额在 2025 之后不再出现，这正是"信号衰减"而不是"信号还在"的形态。

4. **不推荐**：软性按比例减 S1/S2（0.986/0.961，都低于硬清零；触及时折扣打到底才是对的）、只加不减 Aup（0.849，且均仓 53.8% 高于基准，是"加杠杆"而非择时）、Adn 只减不加（0.988，低于 V）、D 方向腿任何权重。

5. **A+ 若要进一步验证**，唯一还缺的是 PBO / CSCV 过拟合检验（本项目至今的唯一空白）：A+ 的优异表现若在组合对称分割下不能稳定出现，就应直接排除。

> **§9-§10 为后续追加**：精确归因显示 A+ 的超额全部来自半仓档内、两个极端桶方向是反的；据此构造的 **A0（只在内档用情绪）夏普 1.215 / Calmar 0.83 / 年化 20.5%**，全面优于 A+。A+ 已被 A0 支配，不再是候选。

- 逐年：A0 除 **2025（25.1% vs 基准 26.4%）** 外每年都赢，2024 43.8% vs 22.3%、2022 +7.8% vs −7.1%、2020 36.0% vs 18.4%。

### 10.1 三段增量（判断衰减的核心）

| 方案 | IS 增量 | 23-26 增量 | 25-26 增量 | 最小值 |
|---|---|---|---|---|
| V 硬否决 | +0.283 | +0.255 | **+0.040** | **+0.040** |
| A0 仅半仓档 | +0.644 | **+0.309** | −0.099 | −0.099 |
| A+ 全档对称 | +0.531 | +0.143 | −0.227 | −0.227 |

A0 在 25-26 仍为负，但比 A+ 好一半（−0.099 vs −0.227）；**V 仍是唯一三段从不为负的方案**。

### 10.2 A0 的风险

1. **放大了 seed 依赖**：36 组 seed 的夏普 std 从基准 0.168 升到 **0.190**（A+ 反而降到 0.136、V 保持 0.169）；最差 seed 夏普 0.282（A+ 0.448、V 0.348）。
2. **它是全时段重仓押注情绪**：51% 的交易日仓位完全由情绪决定。情绪一旦失效，A0 丢掉的是几乎全部超额（25-26 已经是 −0.099）。
3. 虽然四桶结构在三段稳定，但"只留内档"这个决定仍然是从同一份归因里读出来的，属数据驱动选结构；PBO/CSCV 未做。
4. 安慰剂 p=0.000（实际 1.215 高于全部 45 个安慰剂样本，最大 1.049）、36 组 seed Δ 正占比 100%、10bp 成本下仍 1.146——这几项支持它是真信号。

## 11. 更新后的建议

- **A+ 可以淘汰**：A0 在点估计、Calmar、各子区间增量、成本稳健性、安慰剂分位上都优于它，且两者是同一个机制的强弱版本。
- **真正的取舍是 A0 vs V**：
  - 要最高点估计（1.215 / Calmar 0.83 / 年化 20.5%）→ A0。
  - 要"任何子区间都不翻负"+ 最小 seed 依赖 → V（+0.283/+0.255/+0.040，Δstd 0.056）。
- 折中方案值得试：**A0 + V 叠加**（内档用情绪连续化，同时保留极端下尾的硬否决）。§5 的三段表显示两者的加分年份不同（A0 强在 2020/2022/2024，V 强在 2023/2025/2026），可能互补。

## 8. 口径与局限

- 2019 只含 6 月起（策略 2019-06-04 建仓），2026 数据止于 9 月 30 日。
- 连续调制变体（A+/A\*/S1/Adn/Aup）的"换仓次数/年"没有意义（每日都在变），比较应以成本敏感性表为准。
- 36 组 seed 用的是**单 seed 对**做 base（均值 0.450），不是生产用的 6-seed 均值（0.758）；它回答的是"换一组随机种子，增量还在不在"。
- A+ 的 `−0.5` 偏移取 IF 分位的中位数，不是拟合出来的参数；`base + IF − 0.5` 在 IF 近似均匀时均值位移≈0，所以平均仓位 50.5% ≈ 基准 49.1%，增益不来自提高平均暴露。
- 所有结果都是历史回测，不是实盘。
