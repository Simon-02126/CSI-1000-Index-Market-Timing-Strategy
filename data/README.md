# 数据目录（本仓库不包含数据）

本仓库**不含任何行情/两融/市场规模原始数据**——它们来自 CSMAR 与付费数据源，许可不允许再分发。
要跑起来，请按下表准备文件并放回对应目录，列名与 `input/*_字段说明.txt` 对齐。

## `data/`

| 文件 | 内容 | 参考行数 / 区间 |
|---|---|---|
| `两融数据.csv` | 沪深两市融资余额、融资买入额、融券余额（逐交易所逐日） | 8934 行 / 2010-03-31 ~ |
| `市场规模数据.csv` | 各口径板块总市值、总股本、上市股票数、换手率 | 59384 行 / 2008-01-02 ~ |

## `input/`

| 文件 | 内容 | 参考行数 / 区间 |
|---|---|---|
| `中证1000_000852.SH.csv` | 主数据，28 列：开高低收、量额、换手率、两融、板块规模 | 3593 行 / 2012-01-04 ~ |
| `情绪_期权每日统计.csv` | 50/300/500ETF 期权成交量、持仓量、PCR | 7117 行 / 2015-02-09 ~ |
| `情绪_期权IV.csv` | 期权平值/虚值 IV、沽购比、偏斜 | 7117 行 / 2015-02-09 ~ |
| `情绪_期货会员持仓.csv` | IF/IC/IM/IH 前 20 会员持买单量、持卖单量 | 9467 行 / 2015-02-09 ~ |
| `情绪_面板_日频.csv` | 上三张合成的宽表（33 列） | 3594 行；**本策略只取 `IF_会员多空比` 一列** |

`情绪_面板_日频.csv` 可以用 `archive/reports/4.7_情绪数据抓取/merge_sentiment.py` 从三张原始表合成。

## 抓数

`live/db_fetch.py` 负责抓当日数据写入 SQLite（东财 push2his / akshare 中金所 / 交易所板块 / 两融）。
首次建库也可以用 `db/import_csv.py` 把上面这些 CSV 一次性导入。

## 说明

- 数据序列一旦被回补或修正，账本是路径依赖的（死区算子），必须
  `python live/db_update.py --rebuild-oos` 重放，否则账本与信号会对不上。
- 两融按 `effective_date = T+1` 披露滞后建模，查询按 `effective_date <= T` 取。
